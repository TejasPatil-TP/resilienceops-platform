# Contributing to ResilienceOps Platform

Thank you for your interest in contributing! 

## Development Setup
1. Clone the repository.
2. Follow the local setup instructions in `README.md`.
3. Use `make test` to ensure all tests pass before making changes.

## Submission Process
1. Create a feature branch.
2. Make your changes, adding tests where applicable.
3. Submit a Pull Request.
4. Ensure CI actions pass.

## Code Standards
- Python: Follow PEP 8. Use `pytest` for testing.
- Frontend: Use TypeScript. Follow Next.js App Router conventions.
- IaC: Format Terraform using `terraform fmt`.
